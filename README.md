# Blockchain-Based-Immutable-Land-Registry-System

     Built a full-stack blockchain platform enabling secure land registration through NFT-based digital ownership certificates with E-Notary authentication and Zero-Knowledge Proof privacy protection, automating property transfers via smart contracts to prevent fraud and duplication.

# Features
     
     NFT certificates representing land ownership

     E-Notary verification process

     Zero-Knowledge Proof for privacy

     Automated property transfer via smart contracts

     Immutable, transparent ledger

# Tech Stack

     · Solidity 
     · Ethereum 
     · Hardhat/Truffle 
     · React 
     · Web3 
     · MetaMask
